# AquaPulse Website

AI-powered water treatment monitoring platform: marketing site.

## Files
- `index.html`  – page structure and content
- `styles.css`  – all styling (design tokens are CSS variables at the top)
- `script.js`   – FAQ accordion, mobile menu, live sensor simulation

## Run
Open `index.html` in any browser. Keep the three files in the same folder.
Internet is only needed for the Google Fonts (IBM Plex Sans / Mono).

## Customise
- Colours: edit the `:root` variables at the top of `styles.css`
- Contact email: search for `hello@aquapulse.io` in `index.html`
- Live readings in the hero panel are simulated in `script.js`
